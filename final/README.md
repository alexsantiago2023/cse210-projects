# Home Library Manager

## Overview

This program allows the user to keep track of their collection of books.

## Need to know

The code is pretty rudimentary so any errors in the syntax and it may throw the code off.

Make sure when typing in names of titles, authors, etc., you are case sensitive.

You can add your own books to the collection and play with the menu on your own,
or I added a .txt file with 20 books you can display, add to, or remove books from.

## Specific syntax

When running SaveLibrary() or LoadLibrary() make sure to include ".txt" at the end of the file name.
